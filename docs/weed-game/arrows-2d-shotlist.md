# Four Arrows, 2D motion-comic version: SHOT LIST (authoritative)

Style: hand-drawn feel in vector (SVG/canvas): thick wobbling outlines, cel shading (flat color + one shade shape),
hatching, paper grain, line boil "on twos" (re-jitter the outlines every 2-3 frames ~12 fps), limited animation: held
drawings + camera moves, hard cuts, speed lines, impact frames (1-3 frames of black/white inversion with a radial burst).
No blood (PEGI 12): dark shadow shapes, fur tufts, sparks, dust rings. Outdoors: green meadow, big dramatic clouds, blue
mountains, rock pile. P4 = quadruped lion-like monster (big mane, scar studs on brow, a bare patch on the left chest).
Total about 50 s, 37 shots, average 1.3 s. Hard cuts between shots; never the same framing twice in a row.
